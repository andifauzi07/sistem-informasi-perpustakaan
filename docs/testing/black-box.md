# Katalog Kasus Uji Black-Box (BAB IV & ISO/IEC 25010)

Dokumen ini mencatat katalog pengujian fungsionalitas (*functional suitability*) sistem informasi perpustakaan SMKN 1 Selayar menggunakan metode *black-box testing* dan otomatisasi pengujian *end-to-end* (E2E) Playwright.
